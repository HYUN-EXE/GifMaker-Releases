# GifMaker Releases

Public release repository for GifMaker packages and update metadata.

This repository does not contain the GifMaker application source code, credentials, or development environment files.

Release assets may include:

- `GifMaker_Setup.zip`
- `GifMaker_Setup.zip.sha256`

The updater manifest is published as `update.json` only after its matching ZIP and checksum are available in a public GitHub Release.
